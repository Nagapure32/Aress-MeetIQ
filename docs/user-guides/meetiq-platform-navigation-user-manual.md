# MeetIQ Platform Navigation User Manual

Use this manual when you want to open the MeetIQ dashboard and move step by step through the main platform areas.

## 1. Open the Dashboard

1. Open the MeetIQ web app link provided by your administrator.
2. Sign in with your Microsoft work account.
3. After sign-in, MeetIQ opens the **Dashboard**.
4. If you are already inside another section, select **Dashboard** from the left navigation menu.

On smaller screens, select the menu icon in the top-left corner first, then select **Dashboard**.

## 2. Understand the Dashboard Layout

The dashboard is the main starting point for daily work.

1. Review the greeting area at the top for a quick summary of open follow-ups, overdue work, and upcoming meetings.
2. Review the metric cards for **Meetings today**, **Open follow-ups**, **Overdue**, and **Completion rate**.
3. Use **Upload recording** if you need to add an audio or video recording manually.
4. Select **Meetings** near the top-right area to open the Meetings page.
5. Review **Today's meetings** to see upcoming meetings.
6. Select **View all** in the Today's meetings panel to open the full Meetings page.
7. Review **Recent activity** to see recent assistant updates.
8. Review **Today needs attention** for overdue tasks or approval items.
9. Select any attention item to open the related page, such as **Tasks** or **Approvals**.

## 3. Use the Main Navigation Menu

The left navigation menu is available from every main platform page.

1. Select **Dashboard** to return to the home dashboard.
2. Select **Meetings** to review synced meetings and uploaded recordings.
3. Select **Tasks** to manage meeting follow-ups.
4. Select **Transcripts** to open completed meetings with transcript lines.
5. Select **AI Chat** to ask questions about meeting transcripts.
6. Select **Insights** to review productivity charts and weekly workload.
7. Select **Settings** to update Meeting Assistant behavior.

On smaller screens:

1. Select the menu icon in the top-left corner.
2. Select the section you want to open.
3. The navigation panel closes after the new section opens.

## 4. Use Search to Move Around Quickly

The search box appears in the top bar on desktop and below the top bar on smaller screens.

1. Select the search field.
2. Type a section name, meeting title, task title, or related keyword.
3. Review the matching results.
4. Select **Open** on the result you want.
5. Press **Enter** to open the first result.
6. Press **Escape** to clear the search field.

## 5. Navigate Meetings

Use **Meetings** to review calendar meetings, uploaded recordings, meeting status, transcripts, summaries, and linked tasks.

1. From the dashboard, select **Meetings** in the left navigation menu or select the **Meetings** button at the top of the dashboard.
2. Review the **Meeting list** table.
3. Use the status key to understand meeting state:
   - Blue means joining, active, or processing.
   - Orange means the meeting needs attention.
   - Grey means another status, such as completed.
4. Select the filter button in the Meeting list header.
5. Choose **All**, **Upcoming**, **Completed**, or **Transcript ready**.
6. Use **Previous** and **Next** at the bottom of the table to move between pages.
7. Select a meeting row to open the meeting detail page.
8. Select **Back to meetings** on the detail page to return to the Meetings page.

## 6. Upload a Recording

Use this when you have an audio or video file that should become a meeting record.

1. From the dashboard or Meetings page, select **Upload recording**.
2. Enter the **Meeting title**.
3. Select the **Meeting date** if you know it.
4. Choose the recording file.
5. Select **Upload**.
6. If processing completes immediately, MeetIQ opens the meeting detail page.
7. If processing continues in the background, return later to Meetings or Transcripts to review the completed output.

## 7. Ask the Bot to Join a Meeting Manually

Use this from the Meetings page when a Teams meeting should be sent to the bot manually.

1. Open **Meetings**.
2. Select **Join meeting**.
3. Choose an **Existing meeting** if the meeting is already listed.
4. If it is not listed, choose **Paste details manually** and enter the meeting URL or meeting ID.
5. Enter a passcode if the invite requires one.
6. Select **Use service-hosted media** only when your administrator has asked you to use it.
7. Select **Send to bot**.
8. Review the success or error message shown in the form.

## 8. Review a Meeting Detail Page

The meeting detail page is opened by selecting a meeting from Meetings or Transcripts.

1. Review the meeting title and date at the top of the page.
2. Check **Current status** to understand whether the meeting is pending, active, completed, or needs attention.
3. Check **Transcript lines** to confirm whether transcript content is available.
4. In the large left panel, select **Transcript** to read transcript lines.
5. Select **AI Chat** to ask questions about this meeting only.
6. Review **Summary** for the AI overview, key points, and decisions when available.
7. In **Meeting tasks**, select **Generate AI tasks** to create suggested tasks from meeting content.
8. Select **Create task from meeting** to create a linked task manually.
9. Enter or edit the title, description, priority, and due date.
10. Select **Save linked task**.

## 9. Use Meeting AI Chat

AI chat is available from a meeting detail page and from the global **AI Chat** section.

From a meeting detail page:

1. Open a meeting with transcript lines.
2. Select the **AI Chat** tab.
3. Select the prepare or reindex button if the chat is not ready.
4. Type a question in the message field.
5. Select the send button or press **Enter**.
6. Review the answer and open **Evidence lines** when shown.

From the AI Chat section:

1. Select **AI Chat** in the left navigation menu.
2. Search or select a meeting from the meeting list.
3. Prepare chat if needed.
4. Type a question about the selected meeting transcript.
5. Send the message and review the answer.

## 10. Navigate Tasks

Use **Tasks** to review and update meeting follow-ups.

1. Select **Tasks** in the left navigation menu.
2. Review the summary cards for total, open, blocked, done, and overdue tasks.
3. Use the search field to find tasks by task, meeting, or owner.
4. Use **All statuses** to filter by status.
5. Use **All priorities** to filter by priority.
6. Select a task row to view details in the right panel.
7. Change the task status from the **Status** dropdown.
8. Select the linked meeting card to open the related meeting.
9. Select the delete button only when the task should be removed.
10. Use **Previous** and **Next** to move through task pages.

## 11. Navigate Transcripts

Use **Transcripts** to open completed meetings with available transcript lines.

1. Select **Transcripts** in the left navigation menu.
2. Review the table of completed meetings.
3. Check the date, meeting title, transcript line count, and status.
4. Select a transcript row to open the meeting detail page.
5. Use the Transcript tab on the meeting detail page to read the transcript.

If no transcripts are listed, wait until a meeting has completed and transcript processing has finished.

## 12. Navigate Approvals

Approvals may be opened from dashboard attention items or directly at the Approvals page route.

1. From the dashboard, review **Today needs attention**.
2. Select a pending approval item if one appears.
3. On the Approvals page, review the **Pending**, **Approved**, and **Rejected / expired** counters.
4. Review each item in the **Approval queue**.
5. Select **Approve** to allow the bot to join a pending meeting.
6. Select **Reject** to prevent the bot from joining a pending meeting.
7. Select the refresh button to reload the approval queue.

## 13. Navigate Insights

Use **Insights** to review weekly meeting and follow-up performance.

1. Select **Insights** in the left navigation menu.
2. Review the overview metrics:
   - Meeting hours.
   - Completion rate.
   - Overdue follow-ups.
   - Assistant status.
3. Review the charts section for workload and follow-up trends.
4. Return to **Dashboard** when you want the daily operating view again.

## 14. Update Meeting Assistant Settings

Use **Settings** to control automation and timing.

1. Select **Settings** in the left navigation menu.
2. Review the summary tiles for source, auto-join, and approval behavior.
3. In **Join behavior**, turn **Enable auto-join** on or off.
4. Turn **Require approval** on if the bot must ask before joining.
5. Change **Service-hosted media** only when instructed by your administrator.
6. In **Timing windows**, update approval lead time, look-ahead window, join early timing, max late join time, and leave grace time.
7. Select **Save settings**.
8. Confirm that the page shows **Settings saved** or no unsaved changes.

## 15. Use the Profile Menu

The profile menu appears as your initials in the top-right corner.

1. Select your initials.
2. Review the signed-in user name and email.
3. Select **Logout** when you are finished using the platform.

## 16. Return to the Dashboard

Use the dashboard as the starting point whenever you need to reorient.

1. Select **Dashboard** in the left navigation menu.
2. On smaller screens, open the menu icon first, then select **Dashboard**.
3. Review the metrics, today's meetings, recent activity, and attention items before moving to another section.

## Troubleshooting Navigation

- If a section shows empty data, confirm that the Microsoft calendar is connected and the backend services are running.
- If transcripts or AI chat are unavailable, wait until transcript lines have been captured for the meeting.
- If approvals do not appear, confirm that approval mode is enabled in Settings and that the Teams app setup is complete.
- If search does not find a result, try a shorter keyword or open the section from the left navigation menu.
- If you cannot see the left navigation menu, use the top-left menu icon.
